# 🏥 AI Disease Symptom Checker

An AI-powered web application that analyzes symptoms and provides instant health guidance.

## 🌟 Features
- AI-powered symptom analysis using Llama 3.3
- Supports Hindi and English
- Beautiful modern white UI
- Severity level detection
- Home remedies and doctor consultation advice
- Works on mobile and desktop

## 🛠️ Tech Stack
- **AI Model**: Llama 3.3 via Groq API
- **Backend**: Python, Flask
- **Frontend**: HTML, CSS, JavaScript
- **Deployment**: Hugging Face Spaces

## 🚀 How to Run
1. Clone this repository
2. Install requirements: `pip install -r requirements.txt`
3. Add your Groq API key
4. Run: `python app.py`
